Esta pasta registra diagnósticos e investigações realizados no tema WDNA do Site do Ar. Os relatórios distinguem evidências observadas, hipóteses ainda não comprovadas, alterações executadas e rollbacks.

## Regra de segurança

Os relatórios não substituem backup do tema nem autorizam alterações na loja. Qualquer execução deve ocorrer em fase própria, com aprovação explícita, backup identificável e validação pública.
